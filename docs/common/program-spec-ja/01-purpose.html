FAQ HUB CHATBOT / PROGRAM SPECIFICATION

01 文書の目的

この文書は、FAQ Hub Chatbotの画面、データ、処理の流れ、APIを説明するプログラム仕様書です。機能を確認する人、プログラムを保守する人が、画面上の操作と内部処理を結び付けて読める構成にしています。

対象となる機能

ログイン、サイトごとのアクセス権限、FAQの登録・承認、Excel一括取込、FAQ画像、AI用資料の取込、チャット、会話履歴、サイト設定、アカウント管理を扱います。
