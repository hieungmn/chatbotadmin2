03 利用者とアクセス権限

操作訪問者スタッフ（staff）管理者（admin）
チャットで質問利用可利用可利用可
FAQ・資料の登録と編集不可権限のあるサイトのみ。保存後は承認待ち。すべてのサイト
承認・却下不可不可可
FAQの下書き保存不可不可個別FAQの作成・編集で可
サイト設定・アカウント管理不可不可可

承認と下書きの違い

状態画面・データの意味回答への利用
承認待ち（pending）スタッフが登録・更新した内容を、管理者が確認する前の状態。利用しない
承認済み（approved）承認した内容。FAQは公開状態、資料は処理完了であることも必要。条件を満たせば利用する
却下（rejected）内容を残したまま利用を停止。FAQの編集も制限される。利用しない
下書き（is_draft=true）管理者が個別FAQを一時保存するモード。スタッフとAI資料には下書きの選択はない。利用しない

管理者が承認すると、FAQの下書きは解除され、利用できる状態になります。却下は下書きとは別の状態です。

却下されたFAQを再び使う場合

Excelの取込を却下→そのファイル内のFAQをロック→FAQ一括取込 → 編集→承認する → 更新→FAQ管理で編集可能

個別に作成したFAQは、管理者がFAQ管理の「承認」から再承認します。「編集して保存」するだけでは却下状態を解除できません。

認証とパスワード

ログイン成功時にJWTという認証用の文字列が発行されます。ブラウザは管理APIの呼出しにこの文字列を付け、Backendはアカウントと権限を確認します。パスワードはbcryptで変換した文字列を保存します。ログインには元のパスワードを入力します。

DBのパスワードとJWT_SECRETはBackendの.envで管理します。HTMLやFrontendに書き込みません。
