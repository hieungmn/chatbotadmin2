FAQ HUB CHATBOT / PROGRAM SPECIFICATION

サイト・ユーザー管理

サイト設定 — 管理者

サイト管理 → サイトを選択 → タブを選択 → 設定を変更 → 保存する → 保存しました。

保存エラー → フォームを保持してエラーを表示。モデルを選択しても、自動でモデルをダウンロードしたり回答を生成したりはしない。

アカウント作成・権限設定 — 管理者

ユーザー名・パスワード・役割を入力 → メンバーを作成 → 入力欄をクリア → 一覧を更新。

サイト権限 → サイトを選択 → 保存する → 閉じて権限を保存。キャンセル → 保存しない。
