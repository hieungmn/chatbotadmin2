FAQ画像

保存済みFAQに画像を追加

FAQ管理 → 編集 → 画像を追加 → JPEG / PNG / WebPを選択 → 画像を保存。

1FAQにつき5枚、1枚5 MBまで。画像の追加・削除はすぐに反映され、キャンセルでは取り消せない。スタッフが画像を変更 → 承認待ち。却下中のFAQは画像も変更不可。
