削除時の参照関係

ON DELETE CASCADEは、親のデータと関連データを一緒に削除します。例：資料を削除すると、その資料の文章区切りも削除します。ON DELETE SET NULLは、参照IDだけを空にして記録を残します。例：FAQを削除しても、search_logsにある過去の質問は残し、matched_faq_idをNULLにします。削除済みFAQが再び回答に使えるという意味ではありません。
