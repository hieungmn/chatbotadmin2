12テーブル・107項目を掲載しています。「必須」はDBでNULLを許可しない項目です。APIや画面での入力必須項目と一致するとは限りません。既定値はschemaの値であり、APIが権限などに応じて設定する値とは区別してください。

DBのNULL不可と、画面・APIの入力必須は別です。ID・日時・Embeddingなどはシステムが設定します。TEXTも、APIの入力制限やアップロード容量の制限を受けます。

admin_users — 管理者・スタッフのアカウント

項目名意味型キー必須既定値・規則
id各レコードを識別するID。自動採番。SERIALPK必須IDを自動採番。重複不可。
username管理画面へのログインに使うユーザー名。VARCHAR(50)—必須前後のスペースを除き、小文字にして保存。同じ名前は登録不可。
password_hash元のパスワードをbcryptで変換した文字列。ログイン時の照合に使う。VARCHAR(255)—必須Backendが生成して保存。利用者はハッシュを入力しません。アカウント作成APIのパスワードは6文字以上。
password_versionパスワードの世代番号。変更前に発行したJWTを無効にするために使う。INTEGER—必須既定値：0。0以上。
full_name画面に表示するユーザーの氏名。VARCHAR(100)—任意既定値なし。値がない場合はNULL。
roleアカウントの役割。adminは管理者、staffはスタッフ。VARCHAR(50)—必須アプリで使う値：admin（管理者）、staff（スタッフ）。省略時はstaff。DBには値の種類を制限するCHECKはありません。
is_activeアカウントまたはサイトの利用を許可するか。BOOLEAN—必須true：利用可能、false：利用停止。既定値：true。
created_atデータを作成した日時。TIMESTAMPTZ—必須日時（タイムゾーン付き）。保存時の現在時刻を自動設定。
updated_at最後に更新した日時。TIMESTAMPTZ—必須日時（タイムゾーン付き）。作成時に現在時刻を設定し、更新時にDBが自動更新。

sites — サイト設定

項目名意味型キー必須既定値・規則
site_idどのサイトのデータかを示すID。VARCHAR(50)PK必須重複不可。レコードを識別する。
site_name画面に表示するサイト名。VARCHAR(100)—必須既定値なし（NULL不可）。
contact_url回答できないときに案内する問い合わせ先URL。TEXT—必須既定値なし（NULL不可）。
home_urlチャットでサイトのトップへ案内するときのURL。TEXT—任意既定値なし。値がない場合はNULL。
theme_colorチャットの基本色。#RRGGBB形式。VARCHAR(7)—必須#RRGGBB形式の7文字。更新APIで形式を確認。既定値：#1B2C4F。
ai_modelFAQの選択や回答作成に使うOllamaモデル名。VARCHAR(100)—必須既定値：gemma3:4b。使用するモデルはOllama側にも用意する。
custom_prompt_rulesサイトごとに追加するAIの回答ルール。TEXT—任意画面・更新APIでは最大2000文字。入力しない場合は追加ルールなし。
avatar_urlチャットのアバター画像のURL。TEXT—任意既定値なし。値がない場合はNULL。
is_activeこのサイトのチャットボットを有効にするか。BOOLEAN—必須true：利用可能、false：利用停止。既定値：true。
created_atデータを作成した日時。TIMESTAMPTZ—必須日時（タイムゾーン付き）。保存時の現在時刻を自動設定。
updated_at最後に更新した日時。TIMESTAMPTZ—必須日時（タイムゾーン付き）。作成時に現在時刻を設定し、更新時にDBが自動更新。

created_atデータを作成した日時。TIMESTAMPTZ—必須日時（タイムゾーン付き）。保存時の現在時刻を自動設定。
updated_at最後に更新した日時。TIMESTAMPTZ—必須日時（タイムゾーン付き）。作成時に現在時刻を設定し、更新時にDBが自動更新。
