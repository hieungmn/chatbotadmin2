FAQ HUB CHATBOT / PROGRAM SPECIFICATION

11 用語と参照先

用語

用語意味
サイト（site）本システムで管理するWebサイト。FAQ、資料、設定、権限をサイトごとに分ける。
OllamaPCなどでAIモデルを動かすソフトウェア。本システムでは検索用数値の作成、FAQ選択、回答作成を行う。
チャットウィジェット（widget）Webサイトに表示する小さなチャット画面。
質問候補（suggested topics）利用者が押して質問できる候補。API名はsuggested_topics。最大3件。
回答の根拠回答の内容を裏付ける、登録済みFAQや資料の本文。
Embedding文章の意味を数値に変換する処理。本システムでは768個の数値を使用。
文章区切り（chunk）資料から切り分けた本文の一部分。関係する部分だけをAIへ渡すために使う。
Vector数値の並び。Embeddingの結果をDBに保存する形式。
Cosine2つのVectorの方向を比べ、意味の近さを評価する方法。
HNSW近いVectorを速く見つけるためのインデックス方式。
RAG質問に関連する資料を検索し、その本文を根拠としてAIが回答する方式。
JWTログイン後に受け取る認証用の文字列。APIに送ると、サーバーが誰の要求かを確認できる。
bcryptパスワードを照合用の文字列に変換する方式。DBに元のパスワードを保存せずに確認できる。
transactionDBへの一連の書込みをまとめる仕組み。すべて成功すればCOMMIT、途中で失敗すればROLLBACKで取り消す。
MiddlewareAPI本体の前後に共通して実行する処理。認証、権限確認、エラー処理など。
Multerファイル付きのHTTP要求を受け取るBackendのライブラリ。
is_fallback通常の答えではなく、補足や問い合わせの案内を返したかを示す。
answer_status回答処理の結果。answered、insufficient_context、provider_error。
HTTP statusAPIの処理結果を表す番号。200：成功、401：未認証、403：権限不足など。
PK / FKPKは行を区別する主キー。FKは別テーブルの行を参照する外部キー。
