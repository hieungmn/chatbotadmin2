FAQ Hub Chatbot プログラム仕様書

FAQ Hub Chatbotは、Webサイトの質問にFAQや資料を使って回答するシステムです。登録したFAQを優先し、適切なFAQがなければ、承認済みの資料を探してAIが回答を作成します。管理画面では、内容の登録・承認とサイト・アカウントの管理を行います。
