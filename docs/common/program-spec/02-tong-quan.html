2.1 Luồng dữ liệu chính

Nội dung FAQ

Nhập câu hỏi/đáp án → kiểm tra quyền và trùng → lưu FAQ → duyệt và công khai → trả đúng đáp án đã đăng ký.

Tài liệu AI

Upload file → đọc văn bản → chia đoạn → tạo embedding → giao dịch lưu file và đoạn → duyệt → tìm đoạn để AI trả lời.

Phản hồi

Câu trả lời → người dùng chọn hữu ích/chưa hữu ích → lưu liên kết tới câu trả lời → tổng hợp theo tháng, site và nguồn.

PostgreSQL là máy chủ dữ liệu; pgAdmin 4 và A5:SQL Mk-2 là công cụ kết nối quản lý. Các file extension pgvector thuộc cài đặt PostgreSQL. URL liên hệ, avatar và liên kết chi tiết FAQ vẫn được dùng; chúng không phải chức năng nhập tài liệu từ URL.
