Nhập tài khoản rồi bấm ログイン

Bố cục màn hình: Ảnh giới thiệu ở bên trái; biểu mẫu đăng nhập ở bên phải gồm tên tài khoản, mật khẩu và nút ログイン. Thông báo lỗi xuất hiện ngay trên biểu mẫu.

Điền ユーザー名 và パスワード, sau đó bấm ログイン. Nút đổi thành 確認中… và các ô tạm khóa. Backend kiểm tra tài khoản, mật khẩu và trạng thái hoạt động; bước này không gọi AI.

Đăng nhập thành công chuyển sang màn hình quản lý FAQ

Khi API xác thực thành công, trình duyệt lưu token và chuyển từ trang đăng nhập sang FAQ管理. Menu và site được hiển thị theo tài khoản. Nếu đăng nhập sai, vẫn ở trang đăng nhập, giữ các ô đã nhập và hiện lỗi để sửa lại.

Ảnh mô phỏng kết quả API để giải thích giao diện; luồng xử lý được đối chiếu source. Tra cứu hợp đồng API · Tra cứu xử lý lỗi.
