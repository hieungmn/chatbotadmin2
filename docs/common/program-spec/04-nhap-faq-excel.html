Nhập FAQ từ Excel

Chọn file tại FAQ一括取込

Bố cục màn hình: Vùng chọn file ở bên trái, danh sách các lô nhập ở bên phải. Bản xem trước và nút nhập xuất hiện phía dưới sau khi đọc file.

Chọn site rồi bấm vùng chọn file Excel. Trình duyệt đọc sheet đầu tiên; chưa gửi FAQ vào database. Các cột cần theo thứ tự data_id, site_id, category, question, keywords, answer_text, redirect_url.

Kiểm tra bản xem trước rồi bấm nút nhập

Sau khi chọn file, màn hình hiện các dòng đọc được và nút “…件を取り込む”. Bấm nút này để gửi các FAQ hợp lệ lên backend; trong lúc chờ nút hiện 同期中…. Thành công vẫn ở trang này: bản xem trước được xóa, thông báo số dòng nhập/bỏ qua xuất hiện và danh sách lô được tải lại. Dòng trùng không ghi đè; lỗi giữ bản xem trước để thử lại.

Ảnh mô phỏng kết quả API để giải thích giao diện; luồng xử lý được đối chiếu source. Tra cứu hợp đồng API · Tra cứu xử lý lỗi.
