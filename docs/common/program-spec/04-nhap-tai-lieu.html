Nhập tài liệu AI

Chọn file rồi bấm アップロードする

Bố cục màn hình: Thanh đầu chọn site; bên trái chọn định dạng, chọn file và upload; bên phải là danh sách tài liệu, trạng thái và các nút xử lý.

Chọn Word, Excel hoặc PDF rồi chọn file. Tên file và nút アップロードする xuất hiện trong vùng nhập. Đổi loại tài liệu sẽ bỏ lựa chọn file cũ. Bấm nút upload để bắt đầu xử lý, không chuyển trang.

Trong lúc chờ: nút đổi thành アップロード・処理中…

Nút upload bị khóa để tránh bấm lặp. Backend đọc văn bản, chia thành các đoạn rồi gọi model embedding của Ollama cho từng đoạn. Đây là tạo vector tìm kiếm, chưa phải yêu cầu AI trả lời câu hỏi. Khi vector hợp lệ, backend lưu tài liệu và các đoạn trong một giao dịch.

Hoàn tất: tài liệu xuất hiện trong danh sách

Màn hình hiện アップロードが完了しました。, bỏ file đang chọn và cập nhật danh sách bên phải. Admin upload được duyệt ngay; staff upload ở trạng thái chờ duyệt. Nếu đọc file, tạo vector hoặc lưu dữ liệu thất bại, màn hình hiện lỗi và giữ file để gửi lại; không có tác vụ retry nền.

Bấm 詳細を見る để kiểm tra văn bản đã nhập

Một hộp nội dung mở ngay trên trang và hiển thị các đoạn đã lưu. Đối chiếu các đoạn với file gốc để biết hệ thống đã đọc được gì. Bấm 閉じる để trở lại danh sách; thao tác xem chi tiết không gọi AI và không sửa tài liệu.

Ảnh mô phỏng kết quả API để giải thích giao diện; luồng xử lý được đối chiếu source. Tra cứu hợp đồng API · Tra cứu xử lý lỗi.
