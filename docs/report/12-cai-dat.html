Cài đặt và vận hành · TÀI LIỆU TIẾNG VIỆT

Chuẩn bị môi trường và cài đặt

Cài đặt trên một máy Windows, theo 7 bước dưới đây.

Hướng dẫn cài đặt lần đầu

1. Cài phần mềm

Chuẩn bị trên máy Windows chạy hệ thống:

Phần mềmPhiên bản / sử dụng
VS CodeMở dự án và chạy lệnh trong Terminal.
Node.js24.x, có kèm npm.
PostgreSQL17.x, 64-bit; từ 17.3 trở lên. Ghi lại cổng, tài khoản và mật khẩu khi cài.
pgAdmin 4Quản lý PostgreSQL và chạy schema.sql.
pgvector0.8.7; cài theo bước 3.
OllamaChạy AI; tải mô hình ở bước 5.
Edge hoặc ChromeMở trang quản trị và cửa sổ chat.

TypeScript được cài cùng các gói dự án ở bước 2, không cần cài riêng.

2. Cài các gói dự án

Mở thư mục dự án trong VS Code → Terminal → New Terminal. Chạy:

cd chatbot-backend
npm ci
cd ..\chatbot-frontend
npm ci

Kiểm tra: Cả hai lệnh npm ci hoàn tất, không báo lỗi.

3. Cài pgvector và tạo database

Cần chuẩn bị

  • PostgreSQL và pgAdmin 4. Đã cài thì dùng bản hiện có.
  • Bộ file pgvector đã biên dịch sẵn, tương thích với phiên bản PostgreSQL và Windows đang dùng.

Các bước cài

  1. Trong pgAdmin, mở Query Tool → chạy SHOW server_version; để xem phiên bản PostgreSQL.
  2. Giải nén bộ pgvector phù hợp. Mở thư mục vừa giải nén, tìm các file ở cột bên trái rồi sao chép vào thư mục ở cột bên phải. Nếu đã cài pgvector thì bỏ qua bước này.

Ví dụ PostgreSQL 17 được cài tại C:\Program Files\PostgreSQL\17:

File lấy từ bộ pgvector đã giải nénSao chép vào thư mục
vector.dllC:\Program Files\PostgreSQL\17\lib
vector.controlC:\Program Files\PostgreSQL\17\share\extension
Tất cả file có tên bắt đầu bằng vector-- và đuôi .sql trong bộ đóC:\Program Files\PostgreSQL\17\share\extension

Nếu PostgreSQL được cài ở nơi khác hoặc dùng phiên bản khác, thay đường dẫn trên bằng thư mục bản đang chạy. Không chép các file vào thư mục pgAdmin.

  1. Trong pgAdmin: Databases → Create → Database → đặt tên faq_hub.
  2. Chọn faq_hub → Query Tool → mở chatbot-backend/database/schema.sql → chạy toàn bộ file.
  3. Làm mới Schemas → public → Tables → kiểm tra có 12 bảng.

Chỉ chạy schema.sql cho database mới, trống. File tự bật pgvector và tạo tài khoản ban đầu.

4. Cấu hình kết nối

Tạo chatbot-backend/.env từ .env.example; nếu đã có thì sửa các giá trị:

DB_HOST=127.0.0.1
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD="mat_khau_PostgreSQL"
DB_NAME=faq_hub
PORT=3000
OLLAMA_URL=http://localhost:11434
JWT_SECRET="thay_bang_chuoi_ngau_nhien"

Điền mật khẩu PostgreSQL vào DB_PASSWORD. Tạo chuỗi JWT_SECRET bằng lệnh sau và chép kết quả vào file:

node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

Tạo hoặc sửa chatbot-frontend/.env:

VITE_API_URL=http://localhost:3000

Ý nghĩa các biến cấu hình.

5. Tải mô hình AI

Mở Ollama. Chạy trong Terminal có kết nối Internet:

ollama pull nomic-embed-text
ollama pull gemma3:4b
ollama list

Kiểm tra: Danh sách có cả hai mô hình. Chỉ cần tải lần đầu.

6. Chạy hệ thống

Bật PostgreSQL và Ollama. Mở hai Terminal tại thư mục gốc dự án:

Terminal 1 — backend:

cd chatbot-backend
npm run dev

Terminal 2 — giao diện:

cd chatbot-frontend
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort

Giữ hai Terminal mở. Truy cập http://localhost:5173/admin/login.

7. Đăng nhập và kiểm tra

  1. Đăng nhập bằng tài khoản khởi tạo: admin / 123456.
  2. Chọn website mẫu, mở cửa sổ chat và hỏi thử một câu trong FAQ.
  3. Tải một tài liệu Word có văn bản, kiểm tra trạng thái đã duyệt rồi hỏi nội dung trong tài liệu.

Sau khi kiểm tra, tạo tài khoản admin riêng, đăng nhập tài khoản mới rồi xóa tài khoản khởi tạo.

Lần dùng tiếp theo: Khởi động, dừng và sao lưu.
