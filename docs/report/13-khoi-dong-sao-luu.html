Cài đặt và vận hành · TÀI LIỆU TIẾNG VIỆT

Khởi động, dừng và sao lưu

Chạy hệ thống và sử dụng trên chính máy đã cài đặt.

Dành cho: Người phụ trách kỹ thuật

1. Khởi động

Bật dịch vụ PostgreSQL và mở Ollama. Nếu Ollama chưa chạy nền thì dùng:

ollama serve

Không chạy thêm lệnh này khi ứng dụng Ollama đã chạy trên cùng cổng.

Từ thư mục gốc dự án, mở hai Terminal riêng:

# Terminal 1
cd chatbot-backend
npm run dev
# Terminal 2
cd chatbot-frontend
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort

Giữ các Terminal mở. Trên cùng máy, mở http://localhost:5173/admin/login và đăng nhập.

2. Dừng và chạy lại sau thay đổi

Chờ tải tài liệu hoặc lưu nội dung hoàn tất rồi nhấn Ctrl+C tại từng Terminal đang chạy. Muốn dùng lại, thực hiện các lệnh khởi động bên trên.

Sửa code hoặc .env của backend thì dừng và chạy lại backend. Sửa .env của frontend thì dừng và chạy lại frontend. Không chạy lại schema.sql cho database đang có dữ liệu.

3. Sao lưu

Trong pgAdmin: chọn database → Backup → chọn định dạng Custom và nơi lưu → chạy. Sao lưu thêm chatbot-backend/uploads/faq-images, tài liệu gốc và .env ở nơi riêng. Kiểm tra phục hồi trên database riêng, không ghi đè database đang sử dụng.
