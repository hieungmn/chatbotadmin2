利用開始

サイトと機能の選択

FAQの追加、資料の取込、チャットの確認を始める前に、対象サイトを選択します。

対象：コンテンツ担当者・管理者

操作するサイトの選択

  1. 画面上部のサイト選択欄を確認します。
  2. 操作するサイトを選択します。スタッフには権限があるサイトだけが表示されます。
  3. 追加・取込・削除の前に、選択中のサイト名を確認してください。
確認すること

FAQ一覧、資料一覧、チャットのプレビューが選択したサイトに切り替わります。

メニューから機能を選択

画面の項目名できること
FAQ管理登録済みの質問・回答を作成・編集・承認・削除します。
FAQ一括取込Excelから複数の質問と回答を取り込みます。
AIナレッジ資料をアップロードし、読み取った本文を確認します。
ウィジェット確認チャットを試し、サイトに設置するコードを取得します。
サイト管理サイト情報、回答方法、チャットの外観を変更します。管理者専用です。
ユーザー管理アカウントを作成し、サイトの操作権限を設定します。管理者専用です。

サイトやメニューが表示されない場合

「 割り当てられたサイトがありません 」は、サイトの操作権限がない状態です。管理者に権限の確認を依頼してください。画面が狭い場合は、メニューボタンで機能一覧を開きます。

管理者はadmin、スタッフはstaffのアカウントです。スタッフが登録した内容は、原則として管理者の承認後にチャットの回答へ使用されます。
