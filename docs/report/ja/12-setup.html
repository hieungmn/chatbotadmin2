セットアップと運用

環境の準備とセットアップ

Windowsの1台のPCに、次の7つの手順でセットアップします。

初回セットアップ

1. ソフトウェアの準備

システムを動かすWindows PCに、次のソフトウェアを用意します。

ソフトウェアバージョン・用途
VS Codeプロジェクトを開き、Terminalでコマンドを実行します。
Node.js24.x。npmを含みます。
PostgreSQL17.x・64-bit（17.3以降）。インストール時のポート、ユーザー名、パスワードを控えてください。
pgAdmin 4PostgreSQLを管理し、schema.sqlを実行します。
pgvector0.8.7。手順3で追加します。
OllamaAIを実行します。モデルは手順5で取得します。
EdgeまたはChrome管理画面とチャットを開きます。

TypeScriptは手順2でプロジェクトのパッケージと一緒に入るため、個別のインストールは不要です。

2. プロジェクトのパッケージをインストール

VS Codeでプロジェクトのフォルダーを開く → Terminal → New Terminalを選択し、次のコマンドを実行します：

cd chatbot-backend
npm ci
cd ..\chatbot-frontend
npm ci

確認： BackendとFrontendの両方でnpm ciがエラーなく完了すること。

3. pgvectorの追加とDBの作成

必要なもの

  • PostgreSQLとpgAdmin 4。インストール済みの場合は、現在の環境を使用します。
  • 使用中のPostgreSQLとWindowsに対応した、ビルド済みのpgvectorファイル一式。

インストール手順

  1. pgAdminで Query Tool を開く → SHOW server_version; を実行し、PostgreSQLのバージョンを確認します。
  2. 対応するpgvectorを展開します。展開先で左欄のファイルを探し、右欄のフォルダーにコピーしてください。すでにpgvectorを追加済みなら、この手順は不要です。

PostgreSQL 17をC:\Program Files\PostgreSQL\17にインストールした場合のコピー先：

展開したpgvectorからコピーするファイルコピー先フォルダー
vector.dllC:\Program Files\PostgreSQL\17\lib
vector.controlC:\Program Files\PostgreSQL\17\share\extension
名前が vector-- で始まり、拡張子が .sql のファイルすべてC:\Program Files\PostgreSQL\17\share\extension

別の場所・バージョンにインストールしている場合は、実際のPostgreSQLのフォルダーに読み替えてください。pgAdminのフォルダーにはコピーしません。

  1. pgAdminでDatabases → Create → Databaseを選択し、DB名をfaq_hubにします。
  2. faq_hubを選択 → Query Tool → chatbot-backend/database/schema.sqlを開く → ファイル全体を実行。
  3. Schemas → public → Tablesを更新し、12個のテーブルがあることを確認します。

schema.sqlは、新規のデータがないDBでのみ実行してください。pgvectorの有効化と初期アカウントの作成も行います。

4. 接続設定

.env.exampleをコピーしてchatbot-backend/.envを作成します。すでにある場合は、次の設定値を変更してください。

DB_HOST=127.0.0.1
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD="your_postgresql_password"
DB_NAME=faq_hub
PORT=3000
OLLAMA_URL=http://localhost:11434
JWT_SECRET="replace_with_random_secret"

DB_PASSWORDにPostgreSQLのパスワードを入力します。JWT_SECRETは、次のコマンドで生成した文字列をコピーしてください。

node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"

chatbot-frontend/.envを作成または編集します。

VITE_API_URL=http://localhost:3000

設定値の説明。

5. AIモデルの取得

Ollamaを起動し、インターネットに接続したTerminalで実行します：

ollama pull nomic-embed-text
ollama pull gemma3:4b
ollama list

確認： 一覧に両方のモデルがあること。取得は初回だけです。

6. システムの起動

PostgreSQLとOllamaを起動し、プロジェクトのルートフォルダーでTerminalを2つ開きます。

Terminal 1 — Backend：

cd chatbot-backend
npm run dev

Terminal 2 — Frontend：

cd chatbot-frontend
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort

両方のTerminalを開いたまま、次のURLへアクセスします： http://localhost:5173/admin/login。

7. ログインと確認

  1. 初期アカウントでログインします： admin / 123456。
  2. サンプルサイトを選択し、チャットでFAQの内容を質問します。
  3. 本文が入ったWord資料をアップロードし、承認済みになっていることを確認して、その内容を質問します。

確認後は、 自分用の管理者アカウントを作成し、新しいアカウントでログインしてから初期アカウントを削除してください。
