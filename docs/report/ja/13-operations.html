セットアップと運用

起動・停止・バックアップ

セットアップしたPCでシステムを起動して利用します。

対象：運用担当者

1. 起動

PostgreSQLのサービスとOllamaを起動します。Ollamaが起動していない場合は、次を実行します：

ollama serve

Ollamaが同じポートで起動済みの場合は、追加で実行しないでください。

プロジェクトのルートフォルダーでTerminalを2つ開きます：

# Terminal 1
cd chatbot-backend
npm run dev
# Terminal 2
cd chatbot-frontend
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort

Terminalを開いたまま、同じPCで次のURLへアクセスします： http://localhost:5173/admin/login 。アカウントでログインしてください。

2. 停止と変更後の再起動

アップロードや保存が完了してから、 Ctrl+C を各Terminalで押します。次回も上記のコマンドで起動できます。

Backendのコードや.envを変更した場合はBackendを再起動します。Frontendの.envを変更した場合はFrontendを再起動します。既存のデータがあるDBでschema.sqlを再実行しないでください。

3. バックアップ

pgAdminでDBを選択 → Backup → Custom形式と保存先を選択 → 実行。次のフォルダーも保存します： chatbot-backend/uploads/faq-images。資料の原本と.envも別途保管してください。復元確認は別のDBで行い、利用中のDBを上書きしないでください。
