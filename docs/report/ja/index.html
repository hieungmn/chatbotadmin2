FAQ Hub Chatbot

プロジェクト概要、設定値、コマンド、セットアップと操作手順を説明します。

対象：利用者・管理者・運用担当者

プロジェクト概要

プロジェクト名： FAQ Hub Chatbot

サイトごとにFAQと資料を管理するシステムです。訪問者がチャットで質問すると、適切なFAQを返すか、承認済み資料をもとにAIが回答を作成します。管理画面では内容の登録・承認、チャットの設定、利用者の権限設定を行います。

環境の準備から、起動 → ログイン → 設定 → コンテンツ管理 → チャット利用の順に説明します。

環境変数

変数設定ファイル意味・設定値
DB_HOSTbackend/.envPostgreSQLのアドレス。同じPCでは127.0.0.1。
DB_PORTbackend/.envPostgreSQLのポート。通常は5432。
DB_USERbackend/.envPostgreSQLの接続ユーザー名。例：postgres。
DB_PASSWORDbackend/.envPostgreSQLに設定したパスワード。Webのログイン用とは別です。
DB_NAMEbackend/.envDB名。例：faq_hub。
JWT_SECRETbackend/.envセットアップのコマンドで生成する秘密の文字列。ブラウザーへ渡さないでください。
PORTbackend/.envBackendのポート。既定値は3000。
OLLAMA_URLbackend/.envOllamaのアドレス。同じPCではhttp://localhost:11434。
VITE_API_URLfrontend/.envセットアップしたPCのBackend URL：http://localhost:3000。
AI_MAX_CONCURRENCYbackend/.env同時にOllamaを呼び出す件数。既定値は1。初回は変更不要です。

Frontendの環境変数だけが画面に組み込まれます。DBパスワードとJWT_SECRETはBackendに保存してください。他の上限には既定値があります。入力方法は次を参照してください： .envの設定手順。
